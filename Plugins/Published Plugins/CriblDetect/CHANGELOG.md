# Changelog

All notable changes to this plugin are documented here. This project
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-14

### Added
- Initial release of the Cribl Detect plugin for Microsoft Security Copilot.
- Nine skills covering detections, alerts, notables, data sources, and pipelines.
- OpenAPI 3.0.1 spec (`CriblDetect-OpenAPI.yaml`) with Bearer-token auth.
- Card formats for Detection, Alert, Notable, and DataSource responses.
- `README.md` with install and troubleshooting instructions.
- `SamplePrompts.md` with triage, coverage, and chained-skill prompts.
